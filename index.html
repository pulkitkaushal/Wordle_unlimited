Integrity rules: the secret word, original secret, salt, commitment, and guess history are created once per game. Every guess is scored by code against the stored secret. Previous guesses are recalculated on every turn; if state or scoring ever becomes inconsistent, the game stops instead of reconstructing or changing the answer.
